# Бот-анализатор ткани для химчистки

Присылаете боту фото ткани мебели — он определяет тип ткани и даёт протокол чистки на основе вашей базы химии.

## Что нужно перед запуском

1. Токен Telegram-бота (получен через @BotFather) — у вас уже есть
2. API-ключ Anthropic — получить на console.anthropic.com → API Keys → Create Key

## Вариант 1. Запуск на своём компьютере (100% бесплатно, без регистраций)

Подходит, чтобы просто проверить, что бот работает. Компьютер должен быть включён и подключён к интернету всё время, пока бот должен отвечать.

1. Установите Python 3.11+ с python.org (если ещё нет)
2. Скачайте эту папку (fabricbot) себе на компьютер
3. Откройте терминал (командную строку) в этой папке
4. Выполните:

```
pip install -r requirements.txt
```

5. Задайте переменные окружения (замените на свои реальные значения):

**Windows (PowerShell):**
```
$env:TELEGRAM_TOKEN="8277373210:AAHrH_R3LxqwUwKh2oUMqRUhNY-T9eT4a_o"
$env:ANTHROPIC_API_KEY="ваш_ключ_anthropic"
```

**Mac/Linux (Terminal):**
```
export TELEGRAM_TOKEN="8277373210:AAHrH_R3LxqwUwKh2oUMqRUhNY-T9eT4a_o"
export ANTHROPIC_API_KEY="ваш_ключ_anthropic"
```

6. Запустите бота:

```
python bot.py
```

7. Если увидели в терминале "Бот запущен и слушает сообщения..." — идите в Telegram и присылайте боту фото ткани.

Чтобы остановить бота — нажмите Ctrl+C в терминале. Пока терминал закрыт, бот не отвечает.

## Вариант 2. Бесплатный хостинг Railway (бот работает 24/7, не нужен свой компьютер)

1. Зайдите на railway.app, зарегистрируйтесь (есть бесплатный стартовый баланс)
2. Создайте новый проект → "Deploy from GitHub repo" (нужно будет загрузить эту папку к себе на GitHub — можно через сайт github.com, кнопка "Upload files", создав новый репозиторий)
3. После подключения репозитория Railway сам определит, что это Python-проект
4. В настройках проекта → Variables → добавьте:
   - `TELEGRAM_TOKEN` = ваш токен бота
   - `ANTHROPIC_API_KEY` = ваш ключ Anthropic
5. Railway автоматически запустит `python bot.py`
6. В логах проекта должно появиться "Бот запущен и слушает сообщения..."

## Как проверить, что всё работает

1. Откройте Telegram, найдите своего бота
2. Отправьте команду /start или любое текстовое сообщение — бот должен попросить фото
3. Отправьте фото ткани дивана или кресла — через несколько секунд должен прийти анализ

## Если бот не отвечает

- Проверьте, что оба токена введены без лишних пробелов
- Проверьте баланс на счету Anthropic (console.anthropic.com → Billing) — без пополненного баланса API не будет отвечать
- Посмотрите логи (в терминале при локальном запуске, или во вкладке Logs на Railway) — там будет текст ошибки
